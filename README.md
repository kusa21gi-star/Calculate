# Calculator - Android App

Beautiful glassmorphism calculator wrapped in Android WebView.

## Kaise APK banega?

1. Ye code GitHub pe push hoga (is tool se)
2. GitHub > Actions tab pe jao
3. Build APK workflow chalega automatically
4. Artifacts me se app-debug.apk download karo

## Features
- Glassmorphism UI with orbs
- History support
- Full offline calculator
- No Termux needed!

## Tech
- WebView loads file:///android_asset/www/index.html
- compileSdk 34, minSdk 21
- androidx.webkit 1.6.1
